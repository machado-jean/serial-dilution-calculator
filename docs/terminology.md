# Terminologia

Os identificadores do código em inglês e os mapeamentos para a terminologia em português voltada ao usuário serão registrados aqui.

| Identificador no código | Terminologia em português |
| --- | --- |
| `Mass` | massa |
| `Volume` | volume |
| `Concentration` | concentração |
| `microgram` | micrograma (`µg`) |
| `milligram` | miligrama (`mg`) |
| `gram` | grama (`g`) |
| `microlitre` | microlitro (`µL`) |
| `millilitre` | mililitro (`mL`) |
| `litre` | litro (`L`) |
